# smer-plugin v3.3.0

猫娘调教插件 —— 基于 Yunzai 框架的猫娘养成调教系统

默认猫娘为群主，也可以投票指定

## 安装

1. 崽根目录拉取：
```
git clone --depth=1 https://github.com/shiomon/smer-plugin.git ./plugins/smer-plugin/
```
国内环境：
```
git clone --depth=1 https://ghfast.top/https://github.com/shiomon/smer-plugin.git ./plugins/smer-plugin/
```

2. 将 smer-plugin 文件夹放入 `Miao-Yunzai/plugins/` 或 `Yunzai/plugins/` 目录下，重启即可。

## 功能概览

在群聊中与猫娘互动，通过调教与宠爱培养专属猫娘。包含状态管理、装备商店、成就系统、投票换人等完整养成玩法。

## 指令一览

> 两种前缀均可使用：`#猫娘` 或 `&`

### 基础指令

| 指令 | 说明 |
|------|------|
| `&面板` | 查看猫娘状态面板 |
| `&商店` | 查看黑市商店 |
| `&购买y编号` | 购买商品（如 `&购买y1`） |
| `&成就` | 查看成就进度 |
| `&帮助` | 帮助指南 |
| `&重置` | 重置猫娘（需二次确认 `&重置确认`） |

### 互动指令

| 分类 | 指令 |
|------|------|
| 调教 | `&鞭打` `&打脸` `&打屁股` `&挠痒` `&羞辱` `&振动` `&猫叫` `&禁闭` `&滴蜡` |
| 宠爱 | `&摸摸` `&投喂` `&抱抱` `&安慰` `&洗澡` `&陪玩` |

### 投票指令

| 指令 | 说明 |
|------|------|
| `&变@群友` | 发起投票替换猫娘 |
| `&同意` | 同意投票 |
| `&不同意` | 管理员/当事人一票否决 |

## 成就系统

共 48 项成就，涵盖以下分类：

- **调教类**：初次调教、千锤百炼、温柔之手
- **服从类**：初识顺从 → 渐趋顺从 → 死心塌地 → 深度臣服 → 永恒臣服
- **涩气类**：涩气初绽 → 欲念渐起 → 欲念缠身 → 欲壑难填 → 极欲化身
- **堕落类**：堕落萌芽 → 渐趋堕落 → 沉沦初现 → 堕落深渊 → 堕落终焉
- **陪伴类**：黏人的猫、久经调教、长长久久、我爱你、一生一世
- **商店类**：衣不蔽体、碎衣狂魔、初入衣柜、全图鉴、半柜芬芳、迷迭香、神装、足控、善解人衣、衣服是什么、裸体猫娘
- **魅力类**：小妖精、姐就是女王、万众倾倒
- **特殊类**：M显现、濒临崩溃、石女、一触即飞、奄奄一息、阎王不收、饥肠辘辘、我饿死也不、你要撑死我、灰姑娘、我有洁癖

## 核心机制

- **暴击检定**：每次互动随机RNG(1-100)，≥阈值触发暴击，数值翻倍
- **训练加成**：状态在最优区间内获得加成，装备multiplier额外提升
- **耐久系统**：普通装有耐久，调教指令随机打掉耐久，耐久归零自动卸装
- **调教币**：调教指令获取，商店购买消耗，初始100
- **投票换人**：3人同意即替换猫娘，管理员/当事人可一票否决，3分钟超时
- **互动冷却**：全局30秒冷却，防止刷屏
